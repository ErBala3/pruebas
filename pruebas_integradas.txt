1. Introducción
El presente documento recoge la planificación, descripción, ejecución y resultados de las pruebas integradas realizadas sobre la aplicación web Fichaje mediante QR. A diferencia de las pruebas unitarias, las pruebas integradas permiten comprobar el funcionamiento conjunto de varios módulos o componentes, verificando que la comunicación entre ellos se realiza correctamente y que el flujo general de la aplicación responde de forma adecuada.

En este proyecto, el sistema integra autenticación de usuarios, gestión de empleados, generación y descarga de códigos QR, registro de fichajes, cálculo de resumen de horas, control de accesos por rol y persistencia de datos en base de datos SQLite. Por ello, las pruebas integradas se han centrado en validar escenarios completos de uso real de la aplicación.

2. Objetivo
Los objetivos de estas pruebas integradas son los siguientes:
- comprobar la correcta interacción entre módulos o funcionalidades relacionadas;
- verificar que el intercambio de datos entre componentes se realiza correctamente;
- validar flujos completos de uso dentro de la aplicación;
- detectar errores que no aparecen en pruebas unitarias aisladas;
- documentar formalmente los resultados obtenidos y las incidencias detectadas.

3. Alcance
Este documento incluye las pruebas integradas realizadas sobre los flujos funcionales principales de la aplicación web, combinando módulos como:
- inicio de sesión y gestión de sesión;
- gestión de empleados;
- generación y descarga de códigos QR;
- registro de fichajes;
- consulta de historial de fichajes;
- cálculo de resumen de horas anuales;
- control de acceso en función del rol del usuario.

No forman parte del alcance de este documento las pruebas unitarias individuales, las pruebas de rendimiento, las pruebas de seguridad ni las pruebas de aceptación final.

4. Descripción general del proyecto
La aplicación Fichaje mediante QR ha sido desarrollada con la finalidad de realizar fichajes de entrada y salida en una empresa mediante un código QR único asociado a cada empleado. El sistema está orientado a entornos empresariales y permite administrar empleados, generar códigos QR individuales, registrar fichajes automáticamente en sentido IN/OUT según el último movimiento, consultar historiales, calcular el balance de horas y administrar usuarios con distintos roles.

La versión principal del proyecto está implementada con Python y Flask, utilizando SQLite como base de datos. El repositorio también contiene versiones y componentes alternativos en Node.js, pero el flujo funcional más completo se encuentra en la carpeta `fichaje_qr/`.

6. Criterios de aceptación
Una prueba integrada se considerará superada cuando todos los módulos implicados en el escenario funcionen de forma coordinada y el flujo completo produzca el resultado esperado.

Se considerará no superada cuando:
- falle la comunicación entre módulos;
- los datos no se transfieran correctamente;
- la base de datos no refleje el resultado esperado;
- se produzca un error no controlado durante la ejecución del escenario;
